# 요구사항 분석서

## 1. 개요

### 1.1 문서의 목적

본 문서는 클라우드 파일 공유 시스템 개발을 위한 요구사항을 정의하고, 시스템이 제공해야 하는 기능과 품질 기준을 명확하게 정리하기 위해 작성한다. 또한 개발 과정에서 팀원 간 기준을 통일하고 프로젝트 진행의 참고 자료로 활용하는 것을 목적으로 한다.

### 1.2 프로젝트 개요

본 프로젝트는 조직 내부 및 외부 협업을 위한 웹 기반 클라우드 파일 공유 시스템을 개발하는 프로젝트이다.

사용자는 파일 업로드 및 다운로드, 폴더 생성, 파일 공유, 권한 설정 등의 기능을 사용할 수 있으며, 안정적인 파일 관리 환경을 제공하는 것을 목표로 한다.

### 1.3 관련 문서

- 프로젝트 정의서
- 프로젝트 관리 계획서
- 품질 요소 측정 문서

# 2. 사용자 요구사항

| 번호 | 요구사항 |
| --- | --- |
| UR-01 | 사용자는 로그인 후 시스템을 이용할 수 있어야 한다. |
| UR-02 | 사용자는 파일을 업로드 및 다운로드할 수 있어야 한다. |
| UR-03 | 사용자는 폴더를 생성하고 파일을 정리할 수 있어야 한다. |
| UR-04 | 사용자는 다른 사용자와 파일을 공유할 수 있어야 한다. |
| UR-05 | 사용자는 파일 접근 권한을 설정할 수 있어야 한다. |
| UR-06 | 사용자는 파일 이름으로 검색할 수 있어야 한다. |
| UR-07 | 사용자는 이전 버전의 파일을 확인 및 복구할 수 있어야 한다. |

# 4. 비기능적 요구사항

# 5. 인터페이스 요구사항

## 5.1 사용자 인터페이스

- 사용자는 웹 브라우저를 통해 시스템에 접근한다.
- 메인 화면에서 파일 목록 및 폴더 구조를 확인할 수 있어야 한다.
- 업로드 및 다운로드 버튼은 사용자가 쉽게 찾을 수 있는 위치에 배치해야 한다.

## 5.2 시스템 인터페이스

- 데이터 저장을 위해 데이터베이스와 연동해야 한다.
- 파일 저장을 위한 스토리지 서버와 연결되어야 한다.

# 6. 제약사항

- 시스템은 웹 기반으로 개발한다.
- GitHub를 이용하여 형상 관리를 수행한다.

- 프로젝트는 팀 단위로 개발을 진행한다.
